# 功能特性

## 内容运营

- **文章管理**：Markdown 撰写、AI 生成摘要、阅读时长自动估算（支持全站重算）、置顶、定时发布、封面图、slug 与归档。
- **投稿审核**：注册用户可投稿，管理端审核（通过 / 驳回必填原因），作者侧可见审核状态。
- **分类 / 标签 / 归档**：三个维度组织内容，前端独立页面导航。
- **图片上传**：管理端图片库，统一供文章引用。

## AI 能力（一大特色）

### 🐰 小魄罗看板娘（访客侧）

首页常驻的无向量 **A-RAG** 智能体。没有向量库，靠 9 个检索与导航工具像人查资料一样回答站内问题：

| 工具 | 用途 |
| --- | --- |
| `search_blog_articles` / `search_article_blocks` / `read_article_window` | 关键词检索（自动合并已审核评论的补充命中）→ 定位证据块 → 读上下文 |
| `read_blog_article` / `search_blog_hotspots` | 读全文 / 查热点 |
| `list_blog_topics` / `list_latest_articles` / `list_popular_articles` | 「你们都写什么」「最近更新了什么」等导航型问题 |
| `get_site_facts` | 站点规模与基本信息 |

她**严格只读**——访客不能通过她改动站内任何内容。

问答链路经过 agentic 收敛：全部对话（含气泡主动搭话）走真 SSE 单通道；**QA 一级缓存**让同题回答从 50 秒降到 0 秒（7 天 TTL 自愈，管理员可清）；回答没引用来源时自动附软警示。

**与内容的闭环**：文章页「可追问导读卡」（一句话导读 + 3 个引导问题，站长采纳后展示）一键唤起她追问；她答不透可一键转成「问千禧」论坛帖；登录用户可跨会话恢复提问历史。

### 🤖 后台 AI 助手（管理员侧）

管理端内置的运维助手，55 个技能覆盖 9 个业务域：统计、文章、评论、AI 日报、提示词、订阅者、站点设置、用户、论坛——外加批量操作（一次处理最多 50 条待审评论 / 举报 / 文章状态变更）与 `call_api`、`execute_sql`（仅超级管理员）两个兜底工具。

技能是 HTTP 路由的薄封装，**参数契约有 26 项自检用例**（`backend/scripts/selfcheck_skills.py`）守护：路径必须存在于路由表、参数名必须被路由声明、必填缺失必须在发请求前拦截。

## 🔥 AI 热点日报

- 定时抓取热点源生成日报草稿，可手动触发补抓
- 人工编辑 / 发布 / 隐藏 / 删除，支持热度分与精选
- 每篇日报保留来源列表，可溯源

## 💬 评论与论坛

- 评论：待审 / 已审 / 被举报三个队列，点赞、管理员回复、举报处理（驳回 / 确认删除）；审核通过的评论进 AI 检索语料
- 论坛：单版「**问千禧**」提问箱——直达站长本人的提问通道，好问答会被整理成署名文章；看板娘答不透时可一键把对话转成提问帖
- 反垃圾：蜜罐字段 + IP 限流双防线

## ✉️ 订阅与通知

- 邮件订阅 / token 退订链接
- 新文章发布自动给订阅者发通知
- 管理端：冻结 / 解冻 / 全站冻结、不活跃订阅者筛查

## 📊 统计与管理

- 站点概览、每日访问、热门文章
- 用户体系：注册 / 登录 / 邮箱验证 / 找回密码 / 用户主页
- 管理后台：一站式文章、评论、用户、设置、图片管理
